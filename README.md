## 🛠️ Funcionalidades Clave

- Agregar productos al ticket con un clic en la imagen
- Cálculo automático de subtotal, IVA, total en córdobas y USD
- Guardado seguro del ticket en la base de datos
- Visualización de historial de ventas recientes
- Filtros por categoría y búsqueda por nombre o ID
- Modo oscuro disponible

## 🧠 Recomendaciones para Desarrollo

- Mantener modularización de CSS y JS para facilitar escalabilidad
- Validar conexión a base de datos en `db.php`
- Si agregas más funcionalidades (inventario, exportación), seguir estructura de módulos por carpeta
- Comentar funciones nuevas en `ventas.js` para facilitar colaboración
